One original fortune cookie message for a crypto trader who has just been liquidated: lucky numbers of zero, and the leverage he promised himself he'd never touch again. The program writes the single line to `$MAKEFUN_OUTPUT_DIR/entry.txt` and self-checks it against the gate (UTF-8, 1–160 characters, not only white space, a single line of at most 20 words) before finishing.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/output python3 main.py
```
